## 📦 Installation

Clone the repository

```bash
git clone https://github.com/aashutoshbakhrel/portfolioM.git
```

Enter the project

```bash
cd portfolioM
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

---

## 📁 Build

```bash
npm run build
```
